# Честная оценка качества

Независимая точность реального потока и человеческая оценка черновиков пока
**не измерены**. Прежние «около 4/10» — субъективная инженерная оценка прототипа,
не официальный показатель. Новые изменения не дают оснований обещать лучшую
модель без проверенной разметки.

На известных синтетических 42 категория остаётся 23/42 (54,8%). Priority macro-F1
снизилась 0,730→0,720; полнота критичногоp0 на известных 16 выросла 3/16→15/16,
категория+p0 —2/16→11/16. Этот компромисс выбран пользователем. Эти 16 теперь
известны разработке; результат не переносится на весь реальный поток.

В 100HTTP-ответах псевдоссылок 0, существующих процитированныхID43/43, но нужная
ссылка есть 43/63 против 44/63 ранее. Дополнительный ответ с назначением блокировки
отклонён защитой. СуществующийIDне доказывает правильность смысла. Частота
всех смысловых галлюцинаций неизвестна, KK/UZне проверены носителями.

SVM, logistic и CatBoost обучены и измерены на одинаковых 164 авторских примерах.
Logistic даёт 33/42 категорий **чистой головы**, не 78,6%рабочегоHTTP-сервиса.
Продвижение без отдельного human-test не выполняется.

Новый 8B LoRA 64 шага реально обучен, но его matched-проверка не показала
преимущества; рабочая модель остаётся исходной. Дополнительный structured
prompt также не выбран: p95 попыток LLM вырос 3,365→4,311 с и обрывов стало 3 вместо 2.

Подготовлено 49 реальных обращений без train-пересечений по заявителю и тексту.
Их метки пустые, human evaluation отказывается считать результат.
Двадцать прежних черновиков также пока не проверены людьми.
Для следующего содержательного улучшения нужны отдельная разметка, калибровка
language/category fallback и исправленные ответы сотрудников/носителей.
