# Оценка улучшений

Общая инженерная оценка текущего помощника — **около 4/10**. Это субъективная
оценка полезности прототипа, а не измеренная точность или результат человеческого
экзамена. Защита и обработка обращений улучшились, но слабое обобщение мешает
повысить общую оценку.

## Что изменилось по измерениям

Одинаковые 100 синтетических обращений и отдельные 42 примера классификации:

| Показатель | До исправлений | После |
| --- | ---: | ---: |
| Ответы с псевдоссылками | 22/100 | 0/100 |
| Правильная категория | 17/42 — 40,5% | 23/42 — 54,8% |
| Macro-F1 категорий | 0,335 | 0,478 |
| Macro-F1 приоритетов | 0,593 | 0,730 |
| Нужная ссылка сохранилась в ответе | 48/63 | 44/63 |
| p95 всех запросов | 3,251 с | 2,984 с |

Полезный результат — меньше выдуманных источников и лучше обработка знакомых
формулировок. Часть опасных черновиков заменяется безопасным сбором сведений,
поэтому обязательная ссылка иногда теряется. В 31 из 100 случаев используется
явный шаблон без вызова LLM; снижение общей задержки не доказывает ускорение
самой модели.

## Главный нерешённый вопрос

На известных критичных примерах результат вырос с 2/6 до 6/6, а после исправлений
по дополнительному набору — до 16/16. Однако на следующих 16 новых критичных
формулировках правильная категория вместе с p0 получились лишь в **2/16 — 12,5%**.
Это серьёзный провал обобщения. Успех на уже разобранных текстах нельзя считать
доказательством надёжного распознавания взлома или пропавшего платежа.

Казахские и узбекские ответы также могут искажать смысл при правильном номере
правила. Проверки ссылок и JSON не подтверждают смысловую правильность.

## Что можно утверждать о модели

В последней итерации веса Qwen3-8B не дообучались. Изменились маршрутизация,
признаки классификации, поиск и проверки ответа. Экспериментальные LoRA не
используются по умолчанию: их проверка не показала преимущества.

Все приведённые наборы синтетические, человеческих эталонов нет. Подготовлены
20 диагностических ответов для ручного редактирования; подтверждённых
человеческих оценок пока 0. Дообучение на непроверенных черновиках не запускалось.

Следующий содержательный шаг — исправленные сотрудниками примеры, проверка
носителями RU/KK/UZ/EN и отдельный контрольный набор, не используемый при правках.
Для самостоятельных ответов игрокам текущего качества недостаточно.
