# Состояние проекта — 31 октября 2026

Локальный Grand Mobile Support Copilot работает через HTTP и batch JSONL.
Выбраны Qwen3-8B Q4_K_M **без LoRA** и новый authored classifier-v2;
все черновики требуют человека. Новый structured prompt выключен по умолчанию.

Финальная проверка: **601 tests + 50 subtests прошли**, exit0. Настоящий batch
RU/KK/UZ:3 валидных ответа, exit0. HTTP 100+42 и отдельный stress16+42 завершены
с **exit2**, потому что условия качества выполнены не полностью.

Пользователь выбрал меньшую долю пропущенных критичных обращений. Снижение
coverage связано с отклонением ещё одного ответа, назначавшего блокировку.
Общее улучшение качества реального потока **не доказано**.

Изучены все 118337 train +1000 valid. Проверенных category/priority нет;
775 заявителей и 187 групп текстов пересекаются между split. Подготовлено 49 слепых
обращений без этих пересечений; подтверждённых человеческих меток 0.
Полнота language detection и смысловая корректность KK/UZ остаются проблемами.

SVM/logistic/CatBoost действительно обучены и сравнены. Logistic дал 33/42
категорий чистой головы на синтетике, но не заменяет 54,8%всего конвейера и
не продвигается без независимой проверки. Qwen LoRA 64 шага действительно
обучен и отклонён; расширенный промпт также отклонён по задержке/обрывам.

Веса и данные остаются в `.private`. После проверки пользователь подтвердил
публикацию исходного кода и отчётов в существующий GitHub-репозиторий.
Исходные обращения, выборки и веса в публикацию не включаются.
