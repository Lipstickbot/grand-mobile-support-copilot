# Состояние проекта

Grand Mobile Support Copilot — рабочий локальный прототип для сотрудника
поддержки. API, поиск и генерация запускаются локально. Все черновики требуют
проверки человеком, автоматическое закрытие отключено.

## Проверка приложения

После очистки репозитория: **546 тестов и 50 subtests прошли**, exit0.
HTTP-сервис и раздел метрик доступны. Код приложения побайтно совпадает с
версией последнего живого измерения; очистка документации не меняла модель.

## Измеренное качество

| Проверка | До исправлений | После |
| --- | ---: | ---: |
| Категория на 42 синтетических примерах | 17/42 | 23/42 |
| Macro-F1 приоритетов | 0,593 | 0,730 |
| Псевдоссылки на 100 обращениях | 22/100 | 0/100 |
| Нужная ссылка в итоговом ответе | 48/63 | 44/63 |
| p95 всех 100 запросов | 3,251 с | 2,984 с |

На 48 уже разобранных стрессовых случаях критичные обращения определились
в 16/16, нужная ссылка сохранилась в 18/24 ответах. Однако на следующих новых
критичных формулировках правильная категория вместе с p0 получились лишь
в **2/16**. Это существенный нерешённый дефект обобщения.

Синтетические примеры не заменяют разметку реального потока. На KK/UZ остаются
смысловые ошибки при правильной ссылке. Веса Qwen3-8B в последней итерации не
дообучались; изменились поиск, маршрутизация и проверки текста.

Подготовлены 20 диагностических ответов для ручного редактирования. Человеческих
оценок пока 0, непроверенные исправления в обучение не включены. Приватные
данные и веса остаются вне репозитория.
